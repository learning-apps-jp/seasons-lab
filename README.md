# 四季のしくみ LAB

地球プリントNo.05「太陽の動きと季節の変化」に対応した理科教材。

`dist/index.html` をブラウザーで開くと、インストールや通信なしで使えます。

- 地球のドラッグ、公転スライダー、春分・夏至・秋分・冬至、自動公転
- 地軸0〜45°、緯度−90〜90°、地方太陽時0〜24時
- 南中高度、昼の長さ、太陽の日周運動、光の広がり
- 5つの学習ミッションと条件設定、説明例

円軌道、地軸方向一定。太陽赤緯 δ = asin(sin ε × sin λ)。南中高度は90°−|緯度−δ|。昼時間は高度0°の時角から計算。大気差・太陽の視直径・地形を含みません。地球の大きさと公転距離は模式的。気温を予測するモデルではありません。

極点・分点・地軸0°が同時に重なる場合、太陽の中心は終日地平線上となるため、昼の長さは比較用の規約値12時間を表示します。

検証: `node check.cjs`
