# 四季のしくみ

地球プリントNo.05「太陽の動きと季節の変化」に対応した理科教材。

`dist/index.html` をブラウザーで開くと、インストールや通信なしで使えます。

- 地球のドラッグ、公転スライダー、春分・夏至・秋分・冬至、自動公転
- 地軸0〜45°、緯度−90〜90°、地方太陽時0〜24時
- 正午の高度、昼の長さ、太陽の日周運動、光の広がり
- プリントと同じ方位配置（南が左・北が右・東が手前・西が奥）の空のドーム
- 軌道の比較、1日の自動再生
- 正午の高度の角度図、12時が上の昼夜リング、光の広がりの図＋同じ面積が受ける日光の割合バー
- 月・金星の満ち欠けとそろえた暗い宇宙背景、説明は折りたたみ

円軌道、地軸方向一定。太陽赤緯 δ = asin(sin ε × sin λ)。正午の高度は90°−|緯度−δ|。昼時間は高度0°の時角から計算。大気差・太陽の視直径・地形を含みません。地球の大きさと公転距離は模式的。気温を予測するモデルではありません。

極点で赤緯0°の場合、太陽の中心は終日地平線上となるため、昼の長さは数値を表示しません。

検証: `node check.cjs`

科学監査：`node audit-numeric.cjs`（独立3Dベクトル197,640条件、昼時間積分880条件、境界条件）。時刻は地方視太陽時で、標準時の暦計算ではありません。詳細は「授業利用の確認.md」。
